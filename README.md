> **Minecraft Trial Version must be installed from the [Microsoft Store] https://apps.microsoft.com/detail/9NBLGGH2JHXJ?hl=en-us&gl=AZ&ocid=pdpshare**

## 📦 Installation Guide

### Step 1 — Download & Extract
```
Download: Minecraft Mod Installer 26.20++.zip
Source: Releases section of this repository
Then extract the archive to any folder.
```

---

### Step 2 — Open AppData
```
Press:  Win + R
Type:   %appdata%
Press:  OK
```

---

### Step 3 — Locate Game Folder
```
AppData\Roaming\
        └── Minecraft Bedrock\
                └── mods\       ← open this folder
```
> If the `mods` folder does not exist — **create it manually**.

---

### Step 4 — Install Mod File
```
1. Delete everything inside the mods folder
2. Move  →  minemod.dll  →  into the mods folder
```

---

### Step 5 — Install Runtime Library
```
Open:   C:\XboxGames\Minecraft for Windows\Content\
Move:   vcruntime140_1.dll  (from the zip)  →  into that Content folder
```

---

### Step 6 — Launch the Game 🎮
```
Open Minecraft
Enjoy the full experience!
```

---

## 🗺️ File Structure Overview

```
Minecraft Mod Installer 26.20++.zip

```
